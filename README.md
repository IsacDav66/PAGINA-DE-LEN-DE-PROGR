# Resumen del Proyecto: Página Web de Lenguajes de Programación

![image](https://github.com/user-attachments/assets/e954353e-14ca-43e6-a14f-01e641b7de42)


Este proyecto es una página web informativa diseñada para presentar una breve introducción a varios lenguajes de programación comunes. La página tiene como objetivo proporcionar una visión general de cada lenguaje, mostrando ejemplos básicos de código "Hello World" y ofreciendo enlaces a recursos adicionales.

**Características Principales:**

1.  **Presentación de Lenguajes:**
    *   La página incluye una sección dedicada a cada uno de los siguientes lenguajes de programación: Python, PHP, Java, JavaScript, C# y Ruby.
    *   Cada sección presenta un breve texto explicativo sobre el lenguaje, su uso común y sus características principales.
    *   Cada sección incluye una imagen relacionada con el logotipo o icono representativo del lenguaje.
    *   Sección con un titulo centrado "LENGUAJES DE PROGRAMACION"
2.  **Ejemplos de Código "Hello World":**
    *   Cada sección incluye un bloque de código que muestra la sintaxis básica para imprimir "Hello World" en el lenguaje respectivo.
    *   Los bloques de código utilizan la etiqueta `<pre>` y `<code>` para un formato correcto y son resaltados con la libreria highlight.js
    *   Los bloques de código son editables con "contenteditable" para que el usuario modifique el codigo.
    *    Los bloques de código tienen un botón "Copiar código" que permite a los usuarios copiar el código al portapapeles.

3.  **Navegación y Enlaces:**
    *   La página incluye una barra de navegación horizontal con enlaces a recursos externos relevantes: "Descargas", "Documentación" y "Tutoriales".
    *   Se usa la etiqueta `<a>` para crear enlaces externos que llevan a los recursos correspondientes.
    *   Los botones tienen un efecto hover para mejorar la experiencia de usuario.

4.  **Diseño y Estilo:**
    *   La página utiliza un estilo visual consistente y atractivo, con colores definidos en la hoja de estilo `style.css`.
    *   Se utilizan fuentes específicas para los encabezados, párrafos de información y código.
    *   Los contenedores principales del contenido tienen un formato distintivo con bordes redondeados y colores de fondo.
    *   Se utilizan imágenes SVG para los iconos de cada lenguaje, manteniendo la calidad visual a cualquier tamaño.
    *   La pagina se centra en dar una buena experiencia al usuario con efectos visuales, con animaciones en la parte del titulo.

5.  **Elementos Interactivos:**
    *   Los botones tienen efectos hover y cambios de sombra al ser seleccionados.
    *   Se utiliza JavaScript para la funcionalidad de copia de código al portapapeles.
    *   Las secciones principales son separadas por lineas horizontales `hr`.
    *   Se utiliza la libreria "highlight.js" para dar una mejor apariencia al codigo.

6.  **Footer:**
    *   El footer incluye el nombre del creador y un enlace para enviar un correo electrónico.

**Tecnologías Utilizadas:**

*   **HTML:** Estructura la página web y define el contenido.
*   **CSS:** Define el estilo visual de la página.
*   **JavaScript:** Implementa la funcionalidad de copiar código al portapapeles y "highlight.js" para el resaltado de codigo.
*  **highlight.js:** Libreria para resaltar codigo
* **SVG:** Se utiliza este tipo de archivo para los logos de los lenguajes de programacion, para una mayor calidad.

**Propósito:**

La página web sirve como una introducción básica y rápida a varios lenguajes de programación. Está diseñada para estudiantes o cualquier persona que desee tener una primera toma de contacto con estos lenguajes, proporcionando información clara, ejemplos básicos y enlaces a recursos más profundos.

**Para un Trabajo:**
Este proyecto es un buen ejemplo de un sitio web informativo que utiliza las bases de HTML, CSS y JavaScript para presentar contenido de manera clara y concisa. Es un proyecto enfocado en mostrar las habilidades en diseño web y en la presentacion de contenido de una forma amigable al usuario. No tiene funcionalidades complejas y es ideal para demostrar las habilidades básicas de desarrollo web.
